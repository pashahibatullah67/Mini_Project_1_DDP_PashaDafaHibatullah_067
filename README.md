Kelas : B

Tema : Sistem Pencatatan Pengeluaran Harian Mahasiswa

  Pada kesempatan kali ini saya akan menjelaskan alur program tentang sistem pencatatan pengeluaran harian mahasiswa, seperti makanan, transportasi, dan bahkan kebutuhan kuliah ataupun hal yang lainnya. Data pengeluaran tersebut disimpan menggunakan list dan tuple, yang dimana di dalamnya ada pengeluaran, kategori, hingga nominal atau harga barang tersebut.

  Program saya punya beberapa fitur utama, seperti tambah, lihat, ubah, dan bahkan hapus pengeluaran. Program saya juga menggunakan perulangan while supaya menu dapat digunakan secara berulang, dan tentu saja menggunakan percabangan if-ekif-else untuk menentukan pilihan dan mengecek input dari pengguna. Dan tentu saja jika ingin melihat jumlah nominal barang, kita tidak bisa melewatkan total dari nominal barang yang telah kita beli.
